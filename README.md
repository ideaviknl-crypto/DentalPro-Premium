# DentalPro Premium

A premium dental clinic web application concept built with Next.js on the frontend and a Laravel-ready API structure for appointments and real-time clinic features.

## Project structure

- `frontend/` — Next.js + Tailwind premium landing experience
- `backend/` — Laravel API starter for services, doctors, and booking routes

## Frontend

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:3000

## Backend

```bash
cd backend
composer install
php artisan serve
```

## Features included

- Premium hero section and clinic branding
- High-converting appointment booking CTA
- Services, doctor profiles, and testimonials
- Real-time queue and patient status widgets
- Responsive Gen Z-friendly design
- Laravel-ready REST endpoints for clinic data

## Recommended next steps

- Connect the frontend to `/api` endpoints
- Add authentication and admin dashboard
- Integrate live chat/websocket updates with Laravel Reverb
- Add analytics, CRM, and booking persistence
